Recruiting, with discernment.

A multi-company applicant tracking system. Candidates apply with just their name, email and CV - or build one in minutes - and can take an optional, human-reviewed Quick Check.

Open the live demo Source on GitHub

The demo runs the full app (server and database) in your own GitHub Codespace. You need a GitHub account; the first start takes a few minutes.

Demo sign-in: demo@example.com / Ulysse-demo-2026
  1. Platform administration: /admin
  2. Company workspace: /app/aegean-analytics - jobs, pipeline, Assessments
  3. Candidate view (signed out): /careers/aegean-analytics - build a CV, apply, take the Quick Check

Three-field application

Name, email and CV are the only requirements. Everything else is optional.

CV Builder

Live preview, optional photo, three templates, real PDF in English or Greek.

Quick Check

3–4 practical questions, server-timed, with extended or untimed options. People decide - never the software.

Multi-company

Each company's data is isolated at the database level, with its own branding and careers page.
